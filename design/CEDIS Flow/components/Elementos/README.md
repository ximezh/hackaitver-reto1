# Elementos

Piezas base: botones, chips de estado, campos, segmentado, barras de avance y los colores de la tarima.

- Botón principal azul de 48 px para la acción del pulgar; `soft` para «Ver más»; `line` para acciones secundarias.
- Chips: azul en proceso, verde correcto, ámbar pendiente, rojo no se recibe.
- Las barras siempre muestran valor y tope.
