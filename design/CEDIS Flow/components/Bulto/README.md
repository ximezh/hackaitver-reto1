# Bulto

Detalle visual de un bulto: primero la imagen, luego su contenido; «Ver más» abre el desglose completo y la etiqueta QR.

Carrusel: bulto cerrado → producto → piezas. Al deslizar después de la última imagen pasa al siguiente bulto de la factura (hojas → lápices → clips), porque cada bulto lleva un solo producto.
