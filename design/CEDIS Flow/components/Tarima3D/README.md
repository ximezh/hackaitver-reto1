# Tarima3D

Tarima virtual en 3D que se gira con el dedo y acomoda los bultos por peso en tres cajas: roja abajo, naranja en medio, verde arriba.

- Arrastra para girar; botones para girar 45°, separar las cajas y volver a la vista inicial.
- Toca una caja (en 3D o en su tarjeta) para ver su desglose.
- «Escanear bulto» manda el bulto a su caja y actualiza peso (x / 1,000 kg), volumen y altura (x / 1.85 m).
