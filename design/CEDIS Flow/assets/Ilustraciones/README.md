# Ilustraciones

Dibujos isométricos generados con el kit Drakaniia/isometric (MIT), estilo Two-tone con acento `brand-600` (#1f5fd6); lápices con acento ámbar y bulto en cartón `kraft`. Úsalos sobre `brand-50` o blanco, nunca recortados ni recoloreados. Productos: bulto, hojas, lápices, clips. Escenarios: cedis, sucursal, anden, caseta, recibo, embarque, agenda, impresora, datos, login.
